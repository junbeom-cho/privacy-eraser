# ADR-008 : 이관 한 건에 접속을 하나만 연다

* 작성일자 : 2026-08-10
* 작성자 : 조준범

## 1. 배경

실행기가 SQL 문장마다 새 JDBC 접속을 열고 닫았습니다. 문장 단위로 완결되어 코드가 단순했고,
HR 샘플(테이블 7개)에서는 40회 정도라 아무 문제가 없었습니다.

실제 데이터로 처음 돌렸을 때 `ORA-12516` 으로 실패했습니다. 상태는
**`134/134 테이블 완료, 인덱스 처리중`** 이었습니다.

테이블이 전부 끝났다는 것은 접속 자체는 된다는 뜻이므로, 접속이 아니라 **횟수**를 의심했습니다.
`DROP` 134 + `CTAS` 134 + 인덱스 184 + 제약조건 + 코멘트 3,300여 개 ≈ **약 3,900회**.
리스너가 이 속도의 접속 폭주를 감당하지 못한 것입니다.

## 2. 결정

포트에 `openSession` / `closeSession` 을 추가하고, 이관 한 건 전체를 접속 하나로 처리합니다.
성공하든 실패하든 `finally` 에서 닫습니다.

열어 둔 접속이 없으면 종전대로 문장 단위로 열도록 남겨, 다른 호출 경로는 영향을 받지 않습니다.

## 3. 결과

- 1.1GB · 134개 테이블이 **41초**에 끝납니다.
- 재발 방지 테스트를 두 개 남겼습니다 — `이관_한_번에_접속도_한_번만_연다`,
  `실패해도_접속을_닫는다`.
- **샘플 데이터로는 드러나지 않는 결함이 있다**는 것을 확인했습니다.
  규모가 20배가 되어야 보이는 문제였습니다.
