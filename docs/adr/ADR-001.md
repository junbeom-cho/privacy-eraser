# ADR-001 : 프론트엔드는 Vue 로 하고 빌드 산출물을 Spring 이 서빙한다

* 작성일자 : 2026-08-07
* 작성자 : 조준범

## 1. 배경

백엔드는 Spring Boot 입니다. 화면이 필요한데, 사내 도구 하나 때문에 배포 대상을 둘로 늘리고 싶지
않았습니다.

프론트를 별도 서버로 띄우면 배포 파이프라인이 두 개가 되고 CORS 설정이 따라붙습니다.
화면 여덟 개짜리 도구에 치를 값으로는 큽니다.

## 2. 결정

Vue 3 + Vite 로 만들고, 빌드 결과를 Spring 의 정적 리소스 경로로 떨어뜨립니다.

```ts
// vite.config.ts
build: { outDir: '../src/main/resources/static' }
```

Vue 를 고른 이유는 템플릿이 HTML 에 가까워 Bootstrap 클래스를 그대로 붙여 쓰기 좋고,
라우터가 공식 패키지로 제공되어 선택지를 고민할 일이 없기 때문입니다.

## 3. 결과

- **배포 단위가 jar 하나**입니다. Docker 이미지도 이 구조를 그대로 따라
  Vue 빌드 → jar 패키징 → JRE 에 jar 만 남기는 3단계가 되고, 결과는 **377MB** 입니다.
  호스트에 Node 도 Java 도 필요 없습니다.
- 프론트를 고친 뒤 `:8080` 에 반영하려면 백엔드를 다시 띄워야 합니다.
  실행 중인 앱은 `target/classes` 사본을 들고 있기 때문입니다. 개발 중에는 `:5173` 을 씁니다.
- 국내 레퍼런스는 React 쪽이 더 많습니다. 단일 배포의 이점이 그보다 컸다고 판단했습니다.
