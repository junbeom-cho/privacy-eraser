# ADR-003 : DBMS_METADATA 대신 ALL_* 뷰를 조립한다

* 작성일자 : 2026-08-10
* 작성자 : 조준범

## 1. 배경

제약조건·인덱스 DDL 을 뽑는 Oracle 의 표준 방법은 `DBMS_METADATA.GET_DDL` 입니다.
한 번 호출하면 완성된 DDL 문자열이 나옵니다.

이관 계정으로 실제로 호출해보니 `ORA-31603` 이 났습니다. `SELECT_CATALOG_ROLE` 이 필요한데,
**받은 DB** 에서 그런 권한을 기대할 수 없습니다. 이 도구는 남이 준 DB 에 붙는 것이 전제입니다.

## 2. 결정

`ALL_CONSTRAINTS` · `ALL_CONS_COLUMNS` · `ALL_INDEXES` · `ALL_IND_COLUMNS` ·
`ALL_TAB_COMMENTS` · `ALL_COL_COMMENTS` · `ALL_SEQUENCES` 를 읽어 DDL 을 직접 조립합니다.

조립 과정에서 두 가지를 걸러냅니다. NOT NULL 은 Oracle 이 CHECK 로 저장하지만 테이블을 만들 때
이미 따라오므로 제외하고, PK·UNIQUE 가 자동으로 만드는 인덱스도 중복이라 제외합니다.

## 3. 결과

- 일반 계정 권한으로 동작합니다.
- 무엇을 복제하고 무엇을 복제하지 않는지가 코드에 명시적으로 드러났습니다.
  트리거·저장 옵션·권한은 복제하지 않습니다.
- 조회 코드가 늘었고, Oracle 뷰마다 동작이 달라 생기는 함정을 떠안게 됐습니다.
  실제로 [ADR-009](ADR-009.md) 에서 그 함정을 밟았습니다.
