# ADR-010 : 이관 대상을 선택값에서 필수값으로 바꾼다

* 작성일자 : 2026-08-10
* 작성자 : 조준범

## 1. 배경

처음에는 이관 대상 접속 정보를 선택값으로 뒀습니다. 프로젝트를 만드는 시점에는 어떤 테이블을
다룰지도 정해지지 않았고, 이관처 없이도 스캔·판정·검수가 전부 가능하다는 이유였습니다.

실제로 써 보니 값이 없을 수 있다는 이유 하나로 `NULL` 분기가 도메인(`hasEditConnection`)부터
API, 화면 잠금, 목록 표시까지 번져 있었습니다. 어차피 이관할 때는 반드시 있어야 하는 값입니다.

## 2. 결정

프로젝트 생성 시점에 **함께 받습니다.** DB 컬럼도 `NOT NULL` 로 바꿨습니다.

계정이 아직 없어도 된다는 점이 이 결정을 가능하게 했습니다. **스키마 이름만 정하면** 되고,
그 이름으로 계정을 만드는 SQL 은 생성·설정 화면이 안내합니다. 오히려 순서가 자연스러워집니다 —
이름 정하기 → 안내 받기 → DBA 가 계정 생성.

## 3. 결과

- 도메인·API·화면 네 곳에서 `NULL` 분기가 사라졌습니다.
- 이관 단계 잠금과 "이관 대상 미지정" 표시가 필요 없어졌습니다.
- 기존 데이터에 `NULL` 이 있으면 마이그레이션이 실패합니다. 적용 전에
  `SELECT ... WHERE edit_schema IS NULL` 로 확인해야 합니다.
