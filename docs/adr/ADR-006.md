# ADR-006 : 지우는 범위를 원본 테이블명으로 한정한다

* 작성일자 : 2026-08-10
* 작성자 : 조준범

## 1. 배경

재이관하려면 이관 대상의 기존 객체를 지워야 합니다. 스키마를 통째로 비우는 것이 가장 깔끔하고
찌꺼기도 남지 않습니다.

문제는 접속 정보를 잘못 넣었을 때입니다. 이관 대상에 운영 스키마를 실수로 적는 순간
그 스키마가 통째로 사라집니다.

## 2. 결정

**원본에 같은 이름이 있는 테이블만** 지웁니다. 이관 대상 스키마를 비우지 않습니다.

```java
// 지우는 범위를 원본에 있는 테이블로 한정해, 접속을 잘못 넣었을 때 피해를 줄입니다.
executor.dropIfExists(project.getEditConnection(), target.tableName());
```

같은 이유로 프로젝트 저장 시점에 원본과 이관 대상이 같은 스키마인지 검사해 거부합니다.

## 3. 결과

- 접속 정보를 잘못 넣어도 피해가 이름이 겹치는 테이블로 제한됩니다.
- **원본에서 사라진 테이블이 이관 대상에 계속 남습니다.** 원본에서 지운 테이블을 이관 대상은
  모르기 때문입니다. 이 문제는 아직 열려 있습니다. 자동 삭제로 바꾸기보다
  미완성 상태를 스키마 안에 드러내는 쪽을 검토하고 있습니다.
