# ADR-007 : 이관 후에 전수를 세어 보여준다

* 작성일자 : 2026-08-10
* 작성자 : 조준범

## 1. 배경

검수 화면은 표본을 **1행**만 보여줍니다. 정책 길이가 값 길이보다 길면 값 전체가 `*` 로만 남는데,
표본으로 뽑힌 행이 마침 긴 값이면 경고가 뜨지 않습니다. 반대로 짧은 값이 뽑히면
실제로는 몇 건 안 되는데 과하게 걱정하게 됩니다.

표본 하나로는 전체가 어떤 상태인지 알 수 없습니다.

## 2. 결정

이관이 끝나면 마스킹 컬럼마다 **전체 행수**와 **통째로 가려진 행수**를 세어 보고합니다.
한 건도 없는 컬럼은 알릴 것이 없어 목록에서 뺍니다.

컬럼마다 따로 세면 테이블을 그 수만큼 훑게 되므로, 테이블 하나를 한 문장으로 한 번만 읽습니다.

## 3. 결과

- 실제 데이터에서 바로 드러났습니다. `BMNO` 계열 컬럼들이 **1000행 중 1000행 전부** 가려졌는데,
  표본만 봐서는 알 수 없는 값이었습니다. 총 26개 컬럼이 목록에 올라왔습니다.
- 집계에 실패해도 이관은 성공으로 둡니다. 데이터는 이미 옮겨졌고 이것은 보고서일 뿐입니다.
